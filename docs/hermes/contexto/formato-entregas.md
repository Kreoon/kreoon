# Formato estándar de entrega de Hermes (cada resultado debe terminar así)

Para que Claude revise rápido y barato, **todo resultado** de Hermes usa estas secciones, en este orden:

```
## ENTREGA
<el entregable listo para usar, sin preámbulos>

## SUPUESTOS
- <lo que asumiste porque no estaba en la tarea>

## DUDAS
- <lo que necesitas que aclare Claude o Alexander; «ninguna» si no hay>

## CHEQUEO PROPIO
- [ ] Cumple todas las reglas de «Prohibido» del paquete de contexto
- [ ] No inventé cifras, nombres ni testimonios
- [ ] Respeté límites de longitud y formato pedidos
- [ ] Marqué como borrador lo que requiere revisión (legal, imagen de personas)
```
